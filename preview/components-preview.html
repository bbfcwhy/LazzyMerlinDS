§ 1 · BRAND STORY

品牌核心 · 慵懶梅林實驗室

LazzyMerlin 是「二人（+ 雙貓）實驗室」，不是單人品牌。梅林（老婆）出主意，威爾用 AI 把她的魔法實現出來。

Lab Members
  • 梅林 · 出一張嘴的魔法師、創意層、決定要做什麼
  • 威爾 · 用 AI 實現魔法、執行層、決定怎麼做
  • 貓貓們 · 全虎斑 + 白底虎斑、陪伴、日常感
  • AI 工具 · 法術本身、把想法壓縮成可執行的產品
Promise

幫你少做、做對、做久。

反效率崇拜（不 worship fast / intense / speed）、反 SaaS 冷工具感、反過度設計、反 LARP（不 cosplay 奇幻）。

Name Origin

Lazzy · `Lazy` 的故意拼法、強調雙 Z 的懶

Merlin · 老婆名字的諧音

氣質關鍵字

要不要
溫暖、親和、耐看冰冷、工具化、科技感
克制、手工、有層次浮誇、華麗、滿版
一點神秘、一點魔法cosplay、奇幻漫畫、紫粉霓虹
冷面笑匠、機鋒、有點搞怪用力過猛、「我很努力」的表演感
認真做工但輕鬆示人正經的企業官腔

魔法感承載原則

魔法感不靠顏色承載、靠字體與裝飾細節。色彩系統是克制的冷暖藍系，魔法氛圍來自：

  • ① 手寫楷體 display（LXGW WenKai TC）— 像手抄本、羊皮紙卷
  • ② Unicode 裝飾字（◈ ❦ ☾）作為 section separator
  • ③ 雙語混排展現跨文化質感
  • ④ Small-caps label + 羅馬數字（MMXXVI）— 古卷感
  • ⑤ 結尾簽名句「Laziness sets your soul free.」

SwiftUI · iOS / macOS

把 Tokens/ 整個資料夾複製到新專案、把 6 個 .ttf 加進 target Resources、就可以開始用。

import SwiftUI

@main
struct MyApp: App {
    init() {
        LMFontLoader.register()  // 註冊 LXGW WenKai TC
    }
    var body: some Scene { WindowGroup { ContentView() } }
}

struct HelloView: View {
    var body: some View {
        VStack(alignment: .leading, spacing: LMSpacing.section) {
            // Brand display (LXGW)
            Text("嗨，我是 威爾")
                .font(.lmDisplayXL)
                .foregroundStyle(Color.ink)

            // UI body (system)
            Text("懶人魔法師慵懶地閃耀著。")
                .font(.lmBody)
                .foregroundStyle(Color.inkMuted)

            // CTA · tactile button
            Button("送出 Primary") {}
                .buttonStyle(TactileRaisedButtonStyle(radius: LMRadius.button))

            // Inline status chip
            LMStatusChip(text: "BETA", icon: "info.circle.fill", color: .primaryBrand)
        }
        .padding(LMSpacing.page)
        .brandPage()  // bg + 自畫 brand header
    }
}
